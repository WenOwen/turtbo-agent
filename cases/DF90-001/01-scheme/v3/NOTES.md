# 01-scheme/v3 来源说明

## 为什么有 v3

v2 把**电机放在进口段**（轮毂在 x∈[0,0.095] 恒为 0.103457 = Ø207），
这与用户手改的 v8 几何**正好相反**。用户指出：**电机装在转子和静子之间，不是装在进口轮毂里；
流道要收缩；转子前的进口直径应当小于电机直径。**

我解析了 v8 的 `geomTurbo` 通道曲线，用户完全正确：

| 位置 | z (m) | 轮毂直径 |
|---|---|---|
| 进口 | 0.000 | Ø160.00 |
| 电机段 | 0.105–0.196 | **Ø188**（最小 Ø187.87） |
| 出口 | 0.300 | Ø226.36 |

机匣全程恒定 0.300。环面积 0.262637 → 0.242481 m²，**−7.69% 单调收缩**。
v2 因此作废（保留不删，它是错误血缘的记录）。

### 轴向排布的依据

不是随手取的，三个约束卡出来的：
- **转子 x=0.050、静子 x=0.230**：按 v8 实测的叶片轴向跨度（转子 ~73 mm、静子 ~89 mm），
  两排各 90 mm 弦长要装得下。v1 的 0.180135 长度装不下两排 —— 这是 v8 加长到 0.300 的真实原因。
- **电机段 0.095–0.185（90 mm）**：79 mm 电机 + 两端各 5.5 mm 余量。
  放在转子末端（~0.087）之后、静子起点（~0.186）之前。
- **总长 0.300**：与 v8 一致（已验证能划网格能算）。

### 进口轮毂 0.080 的理由（**这一条是模型选择，不是数据**）

- v8 用 0.080（Ø160），它是**唯一一套经过三维网格与 CFD 验证过的几何**
- 对应 φ_tip = 0.2449（ṁ=15.093、ρ=1.225、U_tip=191.637）
- **不是从设计点反解出来的。** 反解需要涵道模型，而 v1 那版从 φ_tip 反解出 0.103457 的做法，
  前提是"电机在进口段"，前提已被推翻，所以那个值不作数
- 换一个进口轮毂 = 换一个设计流量系数 = 换一台机器。**这是设计选择，需要用户确认。**

## 推力（见 thrust_1d.json / thrust_1d.csv）

一维设计点上算出来 **127–143 kgf**，而需求是 90 kgf。**这个数不能用，原因见下。**

### 模型校核（模型是对的）

把本案例 CFD 的**真实出口状态**喂进同一个模型：

```
输入：mdot 13.48909 kg/s  P0 102628.00 Pa  T0 289.4150 K  p_inf 101325 Pa
模型算出出口速度     46.0347 m/s
模型算出静推力      620.97 N
CFD 自己算的静推力  618.72 N     相对差 0.363%
```

**模型复现了 CFD。所以矛盾不在模型，在设计点。**

### 矛盾定位：一维的总压升是三维的 2.2 倍

| | 出口总压 | 总压升 ΔP0 |
|---|---|---|
| 一维设计点（6100 rpm） | 105562 Pa | **4237 Pa** |
| 三维 CFD（5000 rpm，v8 几何） | 102628 Pa | 1303 Pa |
| 三维按 n² 折算到 6100 rpm | ≈103264 Pa | ≈1939 Pa |

一维的 `design.total_pressure_ratio = 1.041818` 是**反设计的射击目标**，不是独立证据。
三维在这套几何上只做到 ΔP0 ≈ 1939 Pa（PR ≈ 1.019）。

推力 ≈ ṁ·V_exit，而 V_exit 主要由 ΔP0 决定，所以：
- 用一维的 ΔP0（4237 Pa）→ 127 kgf
- 用三维校核过的 ΔP0（1939 Pa）→ **约 94 kgf**（与 n² 外推的 93.9 kgf 一致）

**所以 90 kgf 这个目标，很可能是达得到的** —— 94 对 90，+4.5%。
但**在方案阶段证明不了**，因为一维方案的总压升不受任何判据约束。

### 这是判据库的一个洞

对标闸门 B-1..B-7 **没有一条查总压比**。`ducted-fan-1d-scheme/SKILL.md` 明确写着：
「总压比与目标一致不构成证据：它是反设计的射击目标」。
于是：**需求 ACC-1 是推力，推力主要由总压比决定，而总压比没有任何判据管。**

## 哪些是数据、哪些是模型假设

**来自数据**
- 轮毂型线的进口值 0.080、面积收缩比 7.69%、轴向排布 —— 取自 v8 geomTurbo 实测
- 电机外径 188 / 轴向长 79 / 余量 4.96 mm —— 需求文件，用户确认
- 三表与对标结论 —— turbo-flow 实际算出
- 已知答案校核的 CFD 数据 —— 04-solve/v2 的 .xmf，已登记

**是模型假设（不是数据）**
- **进口轮毂 0.080 是设计选择**，不是从设计点反解；反解需要涵道模型
- **涵道摩擦未建模**（默认等熵）。thrust_1d.py 里给了 Darcy-Weisbach 与敏感性扫描，
  f=0.02 是引用值（光滑管湍流 Moody 图），不是拟合
- **模型 B 假设完全膨胀到环境压**。亚声速自由射流的出口静压应等于环境压，
  但本设计的出口面积（0.2425 m²）比完全膨胀所需面积（0.1493 m²）**大 1.62 倍** ——
  出口偏大，气流未完全膨胀。真实的射流结构介于模型 A 与 B 之间
- **三维数据来自 v8 几何（跨血缘）**，不是 v3 的 CFD。v3 还没划过网格

## 不确定的地方

1. **v3 能不能真的达到 94 kgf —— 没验证。** 需要把 v3 划网格、跑 CFD。
   现在这个 94 kgf 是从 v8 的 CFD 按血缘接近 + n² 外推来的估算。
2. **出口面积 0.2425 m² 是不是选大了** —— 面积一致性校核说应该是 0.149 m²。
   但那个校核依赖"出口静压必须等于环境压"，而真实涵道出口未必如此。
3. **进口轮毂 0.080 这个设计选择** 是否最优，没做敏感性。
4. **v2 的 0.103457 当初是怎么来的** —— 它由 φ_tip=0.2581 反解，而 0.2581 来自 v1 参数表，
   那张表描述的是 **v7**（另一台机器）。所以 0.103457 对 v7 是对的，对本案的新设计无意义。

**S1 弦长那 8.1% 不是几何做错：** 参数表写 0.0900，几何实测**全展向 81.7–90.0 mm**，
**均值 0.0840、最大值 0.0900** —— 表里的单值等于几何的**最大弦长**，不是均值。
所以「差 8.1%」是拿单值比均值造成的，**不是几何缺陷**。

**参数表自洽（σ=chord·Z/2πr）两排都对不上 —— 已查清：是 v3 的输入没按新流道重算，**
**不是 turbo-flow 的问题，也不是几何的问题：**
- turbo-flow 的 `solidity` 是 `rows[]` 的**输入值**（`models.py:142`；
  `rowphysics.py:48-51` 只在你给了 `solidity_profile` 时才按展向改），
  三表里的稠度是**原样透传的输入**，不是算出来的
- v3 的 R1 `solidity = 0.639` **与 v1 一模一样** —— 而 v3 的流道换了（R1 站中径 0.19294 vs v1 的 0.203887）
- 用 v1 的中径算：σ = 0.09·9/(2π·0.203887) = **0.6323**，与表的 0.639 差 ~1% → **v1 的输入是自洽的**
- 用 v3 的中径算：σ = **0.668**，与表的 0.639 差 4.5% → **v3 的输入没跟着流道改**
**→ 修正动作：重跑 G2 时 `rows[].solidity` 必须按当前流道的半径重算，不能沿用上一版。**
（这也意味着 G3-5 的「参数表自洽」WARN 是**真警报**，指向的是 G2 的输入，不是几何。）

§02 // THE SEVEN GATES

七道闸门，一道都不能少

每道闸门都有自己的契约、判据、和留下的痕迹。gate check 不过——下一道闸门不抬杠。

  1. G0
    需求冻结 / Requirements Freeze
    「我要 45 kgf、≤ 0.42 Mach、η≥0.8」——把它翻译成 5 个未知量、2 个目标区间、3 条红线。冻结后只读。
    plain-language.json 需求问答清单 5 unknowns · 2 ranges
  2. G1
    设计大纲 / Outline
    把模糊需求写成 20+ 条可执行的工程条目。涵道比、级数、叶根/叶尖几何余量、变工况考核点——每一条都可被后续 agent 直接消费。
    OUTLINE.md 小白引导 22 items
  3. G2
    一维通流方案 / 1D Throughflow
    调 turbo-flow 算平均线 / S2 通流。冻结流道尺寸表 + 叶片几何参数表 + 通流计算结果表。三表不锁，下一步不抬杠。
    三表 schema turbo-flow 只读调用
  4. G3
    叶片造型 / Blade Geometry
    cascade-forge 把叶栅参数变成可打开的 .par / .geomTurbo。金属角符号、S2 截面、Simple Bezier 中弧线，全在交接合同里。
    .geomTurbo B-spline 厚度 交接合同
  5. G4
    结构网格 / AutoGrid Mesh
    基于已验证 TRB 模板替换 GeomTurbo，控制第一层高度和叶尖间隙，按 mesh-vN 管理版本。网格不过不进入求解，否则 y+ 报告会被笑话。
    3.1M cells y+ ≈ 1 mesh-v3
  6. G5
    求解 / FINE Solve
    启动 EURANUS，扫工况，监控末段 ṁ 稳定性。收敛只看质量流量——残差只是用来抓 NaN 和爆炸的。
    1248 it ṁ stable EURANUS
  7. G6
    后处理与交付 / Post & Deliver
    CFView 出 B2B 2/50/98% 叶高 + 收敛历史 + 性能三表。整机静推力只看控制体口径：T = ṁout·Vx,out + (pout−p∞)·Aout。XMF 壁面轴向力不算数。
    CFView 三表 45/45 ✓

§05 // THE THREE RULES

三条不可违背的规矩

其余都还可以改。这三条写在 contracts 里，agent 必须一字不差地遵守。

  1. R1

    一个唯一网格 ↔ 一个独立 .iec

    不同网格不得共用工程。版本错了，结论一定错。

  2. R2

    整机静推力只认控制体口径

    T = ṁout·Vx,out + (pout − p∞)·Aout。XMF 壁面轴向力不是整机净推力。

  3. R3

    收敛主判据是末段 ṁ 稳定性

    不是固定残差数值。残差只用于识别 NaN、爆炸与持续恶化。

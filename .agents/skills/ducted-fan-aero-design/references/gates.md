# G0-G6 闸门判据

> 判据分三档：**硬**（不满足即 FAIL，禁止放行）｜**软**（不满足记 WARN，可带条件放行）
> ｜**禁止项**（出现即 FAIL，无论其他指标多好）。
>
> 每条判据都要在 `LOG.md` 里写出来。**没有判据的结论无效。**

---

## G0 需求

**读**：用户口述（可含模糊量词，如"大概 90 公斤推力"）

**做**：执行 [requirements-interview.md](requirements-interview.md) 的 11 项问答

**写**：`requirements.yaml`、`00-brief/open_questions.md`

| 档 | 判据 |
|---|---|
| 硬 | 推力目标、环境条件、桨盘直径、转速上限 **四项齐全且带单位** |
| 硬 | `requirements.yaml` 可被解析；每个数值有 `source` 字段（用户给定 / 推导 / 假设） |
| 硬 | 未决项必须写进 `open_questions.md`，**不得用默认值静默填充** |
| 软 | 电机型号与功率上限已确认 |
| 软 | 交付格式与交付物清单已确认 |

**禁止项**：把用户没说过的约束写成既定事实；对"0 Pa 表压"这类约定不做显式声明。

**出口**：`requirements.yaml` 的 sha256 写入 `manifest.requirement_ref`。此后任何变更 = 全案作废。

## G1 设计大纲

**读**：`requirements.yaml`

**做**：反算流量/压比/功率量级；列设计变量与约束

**写**：`00-brief/design_brief.md`

| 档 | 判据 |
|---|---|
| 硬 | 需求 → 方案的物理链闭合：量纲正确、量级合理、效率不超过热力学上限 |
| 硬 | 设计变量清单与约束清单分开写；每个变量有取值范围与依据 |
| 硬 | 明确"哪些量是设计选择、哪些量是被需求锁死的" |
| 软 | 与同类产品（如舒贝勒 HST 系列）的公开参数做过量级对照 |

**禁止项**：在不说明假设的情况下给出确定性的性能预测。

**出口**：设计大纲中每个待定参数，要么有值，要么明确标为"由 G2 求解"。

## G2 1D/通流方案

**读**：`requirements.yaml`、`00-brief/design_brief.md`

**做**：调用 `ducted-fan-1d-scheme`；一维平均线 + 径向平衡

**写**：`01-scheme/vN/` 三表（流道尺寸表 / 叶片几何参数表 / 通流计算结果表）+ `scheme.json`

| 档 | 判据 |
|---|---|
| 硬 | 三表 schema 通过校验（列名、单位、行数一致） |
| 硬 | 质量守恒：入口流量 = 出口流量（相对差 ≤ 1e-6） |
| 硬 | 欧拉功闭合：`Δh0 = U·(Cθ2 − Cθ1)`，符号与压气机加功为正 |
| 硬 | **对标闸门**：与已知基准的压比 / 效率 / 流量三项偏差，逐项记录实测值与阈值 |
| 软 | 转/静子稠度、展弦比、轮毂比落在工程常用区间 |

**禁止项**：
- 对标不通过却仍标 PASS
- 用"趋势合理"代替数值对标
- 阈值没写来源

**失败出口**：对标不通过 → **如实记 FAIL** → 降级为"专家表格 + 文档化 1D 闭合" →
**不阻塞 G3+**，但要在大纲与交付说明中标注"G2 未通过独立验证"。

## G3 叶片造型

**读**：`01-scheme/vN/叶片几何参数表.csv`、`流道尺寸表.csv`

**做**：调用 `cascade-forge-geometry-handoff`

**写**：`02-geometry/vN/<stem>.geomTurbo` + `<stem>.manifest.json` + `preview.png`

| 档 | 判据 |
|---|---|
| 硬 | 输出路径 **纯 ASCII** |
| 硬 | 截面数与参数表一致；相对展向位置单调递增且覆盖 0→1 |
| 硬 | 每个截面点序闭合、无自交、无重复点 |
| 硬 | 节距与稠度回算一致：`pitch = 2πr/Z`、`solidity = chord/pitch`，相对误差 ≤ 1e-6 |
| 硬 | 前缘/尾缘半径非负；弦长 > 0 |
| 软 | 缩放与坐标方向经预览图目视核对 |
| 软 | 与 `cascade-forge` 的 `audit` 输出一致 |

**禁止项**：手工编辑几何文件绕过参数表；用"能打开"代替几何正确性。

## G4 网格

**读**：`02-geometry/vN/<stem>.geomTurbo` + 已验证 TRB 模板

**做**：调用 `numeca-autogrid-meshing`（或原生 IGG 二维路线走 `numeca-igg-skills`）

**写**：`03-mesh/vN/`：`.trb .igg .cgns .bcs .config .info .qualityReport` + `mesh_audit.json`

| 档 | 判据 |
|---|---|
| 硬 | **负单元 = 0** |
| 硬 | 六件套齐全且同名同目录 |
| 硬 | 块数、块名、每块 `IMAX/JMAX/KMAX` 与 TRB 声明一致（块签名） |
| 硬 | `.qualityReport` 存在且非空 |
| 硬 | 几何/流道与 G3 一致（体积或特征尺寸相对差 ≤ 1e-3） |
| 软 | 最小偏斜角 ≥ 10° |
| 软 | 最大膨胀率 ≤ 5（**该上限来自 CompAI 现行标准，是本项目约定，换项目须重新标定**） |
| 软 | 首层高度与目标 y+ 匹配（需给出估算依据，不是实测） |

**禁止项**：
- "先算了再说"
- 用网格数量增加代替质量结论
- 在无收敛 CFD 指标时宣称"网格无关"或"y+ 合格"

**出口**：网格版本号（`mesh-vN`）与 `.igg` 的 sha256 一并登记；**一个网格对应一个 `.iec`**。

## G5 求解

**读**：`.iec` + `.igg`（用**新网格**重物化，禁止复用旧 `.run`）

**做**：调用 `numeca-fine-solver`

**写**：`04-solve/vN/`：`.iec` + `<project>_<name>/` + `.std` + `convergence.csv` + `verdict.json`

| 档 | 判据 |
|---|---|
| 硬 | 最终 `.run` 中 `GRID_FILE` 指向当前 `.igg`；块签名与 G4 完全一致 |
| 硬 | 边界审计：在最终 `.run` 的 `bc_parameters` 块中确认唯一出口块与目标值 |
| 硬 | 正常结束标记 + CGNS 存在 + 无关键日志错误 |
| 硬 | 末段 `MF_IN`、`MF_OUT` 各自 `100×(max−min)/|mean|` ≤ 0.2%（见 C-002 适用边界） |
| 硬 | 最终质量不平衡 ≤ 1% |
| 硬 | 状态词正确：`finished_unverified` → 验收后才 `accepted`/`rejected` |
| 软 | 轴功率与流体总焓升功率闭合（不闭合是**复核信号**，先查周期扇区/叶片数缩放/扭矩定义/站位总温） |
| 软 | 末段力漂移在合理范围（注意：平均轴向力接近零时会放大该相对量） |
| INFO | y+ —— **仅记录，不判 PASS/FAIL** |

**禁止项**：
- 用固定残差数值硬拒绝工况
- 用退出码 0 或正常结束标记宣布收敛
- 多个工况平铺进共享 `computations/`
- 把压力寻参点与流量寻参点混合排序、连线、拟合

**失败出口**：
- 持续振荡（≥30 min，末 4×500 连续细网格迭代两端均 ≥1% 反复振荡、振幅一致不衰减、均值无明显漂移）
  → 保存退出。**状态按触发来源分两种记法，不得混写**（见 C-011）：

  | 触发来源 | `state` | `reason` |
  |---|---|---|
  | 求解器按策略自动判定 | `rejected` | `persistent_flow_oscillation` |
  | 用户要求保存停止 | `stopped` | `user_stop` |

  两者物理上都是"在振荡中停下"，但审计语义不同：前者是策略判定，后者是人为干预。
  审计"振荡侧边界"时判据是**「高于最高验收背压的第一个未验收点」**，
  **不是** `state == "rejected"`（见 C-011）。
  **这是无效续算的退出判断，不是收敛步数限制。**
- 并行启动失败（MPICH/SMPD 注册表错误、`-machinefile unknown`）→ 由**同一 IEC** 重新物化未分区
  `.run` 再顺序启动；只给分区后的 `.run` 加 `-seq` 仍可能读并行配置。

## 跨闸门规则

1. **一次只做一道闸门。** 上一道 PASS 之前不启动下一道。
2. **阶段状态必须显式更新**（`case_ledger.py stage`），不能靠"文件在就算做完"。
3. **每个产物必须登记**（`case_ledger.py add`），带 `--from` 溯源。
4. **FAIL 也是一条有效结果**，必须登记并写日志，不许静默重试到过为止。
5. **不得跨闸门借用证据**：G4 的网格质量通过 ≠ G5 收敛；G5 收敛 ≠ G6 物理正确。

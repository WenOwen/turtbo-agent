# 小白引导：从一句需求到第一个网格

> 目标读者：**没做过涵道风扇气动设计**，但会装软件、会看命令行的人。
> 原始流程来自 `Ducted-Fan/PPT/涵道风扇文件创建计算指导-20260904.pptx`（27 页）。
> 每一步都写清「**你在屏幕上应该看到什么**」——看不到就是有问题，别往下走。

---

## 开始之前：你需要知道的三件事

**1. 这条链不是"点几下就出结果"。** 每一步做完都要**验收一次**：这一步到底算不算过。
判不过就回头改，不许硬冲。

**2. 残差曲线不是成绩单。** 本项目判收敛看**末段质量流量稳不稳**，不看残差降到几。
残差只用来发现"炸了""出 NaN 了"。

**3. 软件路径里不能有中文。** AutoGrid 会把中文路径下的合法 `.geomTurbo` 报成"格式错误"，
让你查半天文件语法。**先把工作路径设成纯英文。**

---

## 第 0 步：预检

```powershell
python tools/preflight.py all --case cases/DF90-001
```

**应该看到**：授权的 license 特性列表、MPI 可执行文件路径、磁盘剩余、路径 ASCII 检查、projectRoot 检查。
**看不到授权** → 先解决授权，后面全是白干。

---

## 第 1 步（G0）：说清你要什么

**你做什么**：回答 11 个问题（见 [requirements-interview.md](requirements-interview.md)）。
**Agent 做什么**：把它写成 `requirements.yaml`。

**应该看到**：`cases/<ID>/requirements.yaml`，其中每一项都有 `source` 字段
（`user` / `derived` / `assumed`），没答上来的项出现在 `00-brief/open_questions.md` 里。

> ⚠️ **这一步最容易被跳过，也最贵。** "90 公斤推力"到底是整机净推力还是台架轴向力，
> 差一个控制体口径，最后会差几十牛——而这几十牛会让你的方案看起来"差一点没过"。

---

## 第 2 步（G1）：设计大纲

**Agent 做什么**：从需求反算流量、压比、功率量级，列出设计变量与约束。

**应该看到**：`00-brief/design_brief.md`，里面有：
- 需求 → 方案的推导链（每一步算式可追）
- **设计变量清单**（这些是可以调的）
- **约束清单**（这些是锁死的）
- 电机功率是否够的初步判断

**自查**：轴功率 ≤ 电机峰值功率吗？桨尖马赫数超了吗？这两条不过，第 3 步算出来的方案装不上。

---

## 第 3 步（G2）：一维方案

**你做什么**：基本不用动手。若用 `turbo-flow`，它会跑一个一维平均线 + S2 子午面通流。
**Agent 做什么**：调用 `ducted-fan-1d-scheme`，产出三表。

**应该看到**：`01-scheme/v1/` 下三张表：

| 表 | 里面是什么 |
|---|---|
| 流道尺寸表 | 各站位的轮毂/机匣半径、通流面积 |
| 叶片几何参数表 | 每个叶排、每个截面的半径、弦长、稠度、金属角、厚度 |
| 通流计算结果 | 转速、流量、压比、效率、轴功率、推力、无量纲系数 |

**这一步怎么算过**：这就是**对标**。如果你手上有一个已知的同类设计点，两者要对得上。
**对不上不是失败，是发现**——如实记为 FAIL，然后降级走"专家表格"路线，照样能往下走。

> 这一段的诚实程度决定了整个方案的可信度。**不要为了"好看"调数字。**

---

## 第 4 步（G3）：叶片造型

**Agent 做什么**：调用 `cascade-forge-geometry-handoff`，把参数表变成 `.geomTurbo`。

**应该看到**：
- `02-geometry/v1/<stem>.geomTurbo`（文本文件，可以打开看坐标）
- `<stem>.manifest.json`
- `preview.png` —— **打开它看一眼**。叶型是不是像个叶片？有没有自交？前缘是不是尖的？

**这一步怎么算过**：点序闭合、节距/稠度回算一致、前尾缘半径非负。

> ⚠️ 这一步的产物是后面所有东西的地基。**几何错了，网格和 CFD 全是浪费。**
> 宁可在这里多花两小时，不要在跑完 CFD 之后才发现。

---

## 第 5 步（G4）：AutoGrid 划网格

**你做/Agent 做**：用已验证的 TRB 模板替换 `.geomTurbo`，生成网格。

**应该看到**（六件套同名同目录，v7 实测量级供参考）：

| 文件 | v7 参考体积 |
|---|---|
| `.trb` | 36 KB |
| `.igg` | 487 KB |
| `.cgns` | 101 MB |
| `.bcs` | 16 KB |
| `.config` | 13 KB |
| `.qualityReport` | 4.4 KB |

外加 `mesh_audit.json`。

**这一步怎么算过**：负体积单元 = 0（硬）；块签名与 TRB 一致（硬）；最小偏斜角 ≥ 10°（软）。

**看到负体积单元** → 回第 4 步改几何，或改 TRB 模板。**不许"先算了再说"。**

> 💡 如果 AutoGrid 说 geomTurbo 格式错误：**先检查路径里有没有中文**，不是先改文件。

---

## 第 6 步（G5）：FINE 求解

**Agent 做什么**：从 `.iec` + 新 `.igg` 重新物化独立 `.run`，设边界，启动 EURANUS。

**应该看到**：
- `04-solve/v1/<project>_<name>/<project>_<name>.run`
- `.std` 日志在**增长**（不是空文件）
- 迭代在推进

**这一步怎么算过**（全流程最硬的一道）：
- 末段 100 个有效迭代里，`MF_IN` 和 `MF_OUT` 各自的相对极差 ≤ 0.2%
- 最终质量不平衡 ≤ 1%
- 正常结束 + CGNS 完整 + 无关键错误

**看到"振荡不收敛"**：先看振幅是否衰减。持续 30 分钟以上、末 4×500 步两端都在 ≥1% 反复摆、
振幅还不衰减 → 保存退出，标 `rejected`。**这不是失败，这是"这个点在当前设置下算不出来"的结论。**

**看到 MPI 起不来**（注册表错误、`-machinefile unknown`）：别在分区后的 `.run` 上加 `-seq` 硬试，
要从**同一个 `.iec`** 重新物化一个**未分区**的 `.run` 再顺序启动。

---

## 第 7 步（G6）：CFView 出图与交付

**Agent 做什么**：调用 `numeca-cfview-post` 出曲线；调用 `extract-fine-autoblade-tables` 出三表。

**你要做一次选择**：出图前 agent 会把算例分成「压力寻参线 / 流量寻参线 / 独立设计点 / 不可用」，
**问你要按哪条线画**。选一个，不要混。

**应该看到**：
- `05-post/v1/characteristic_curves.png`（特性曲线：压比-流量、效率-流量）
- `05-post/v1/yplus_summary.csv`
- `06-delivery/v1/` 三张 Excel + `dashboard.html`

**这一步怎么算过**：静推力必须闭合 `T = ṁ_out·Vx_out + (p_out − p_∞)·A_out`；
三表里**不能**有文件路径、版本号、质量状态字段。

## 术语表

| 术语 | 一句话解释 |
|---|---|
| **气动设计 / aerodynamic design** | 从需求到首版可验证方案的整个过程（不是"启动电机"） |
| **静推力** | 前进速度为 0 时的推力。控制体口径：`T = ṁ·Vx + (p−p∞)·A` |
| **控制体口径** | 只看进出口截面的动量与压力，不用壁面积分。**整机净推力必须用这个** |
| **XMF 轴向力** | NUMECA 对**选定壁面**的轴向力积分。**不是整机净推力** |
| **总总效率 (η_tt)** | 出口总压/总温相对入口的总压/总温定义的等熵效率 |
| **总静效率 (η_ts)** | 出口**静**压定义的效率；涵道风扇常看这个（推力做功靠静压） |
| **稠度 (solidity)** | 弦长 / 节距。越大叶片越"密" |
| **节距 (pitch)** | 相邻叶片在周向的间距 = `2πr/Z` |
| **金属角** | 叶片中弧线的切线角。**气流角 − 金属角 = 落后角/攻角** |
| **落后角 (deviation)** | 出口气流角与尾缘金属角之差。**符号必须先统一坐标系**（见 C-005） |
| **反力度 (reaction)** | 静压升在转子中的占比 |
| **堵塞 (choke)** | 流量到极限，再降背压流量也不涨 |
| **失速/喘振** | 流量降到极限，流动分离。稳态 CFD 只能看到**趋势**，不能宣称物理边界 |
| **y+** | 第一层网格的无量纲壁面距离。**本流程只记录，不判合格** |
| **膨胀率 / 长宽比 / 偏斜角** | 网格质量三兄弟：单元相邻层尺寸比、细长程度、角度畸变 |
| **块签名** | 网格的块数 + 块名 + 每块 IMAX/JMAX/KMAX。用来证明"求解器读的确实是这个网格" |
| **TRB** | AutoGrid 的网格控制模板。换几何不换 TRB = 保证可比性 |
| **IEC / RUN** | `.iec` 是 FINE 工程（computation 清单的唯一真源）；`.run` 是单个工况 |

**本仓库内部才用的词**（你会在我写给你的话里看不到它们，但看日志时会遇到）：

| 内部词 | 对外就说 | 意思 |
|---|---|---|
| 闸门 | 这一步的检查 | 每步做完自动跑一次，判这一步能不能过 |
| 合同 | 规矩 | 踩过坑之后定下来、必须遵守的一条 |
| 判据 | 判断标准 | 满足什么条件才算过 |
| 产物 | 交出来的文件 | — |
| 案例 | 项目 | — |
| manifest | 文件清单 | 记着每个文件是什么版本、上一版是谁、指纹是多少 |
| 归因 | 查是谁改的 | — |
| 看守 | 文件监视 | 盯着四类关键文件变没变；不拦你，只记录 |
| 登记 | 记一笔 | 把文件记进日志和清单 |

## 五句最该记住的话

1. **残差不是成绩单，质量流量稳定才是。**
2. **静推力只有控制体口径，壁面轴向力不是。**
3. **一个网格一个 `.iec`。**
4. **中文路径会让 AutoGrid 撒谎。**
5. **失败要如实记，不许静默重试到过为止。**

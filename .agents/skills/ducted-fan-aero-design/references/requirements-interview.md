# G0 需求问答清单（11 项）

> **用法**：不要念问卷。按下面的顺序问，能一次问清就一次问清；
> 用户答不上来的项，给默认值**并明确标注"这是假设，不是需求"**，写进 `open_questions.md`。
>
> **铁律**：用户没说过的约束，不得写成既定事实。

---

## 第 1 组：性能目标（必问，4 项）

### Q1 推力

> **问**："这台风扇要出多大推力？静推力还是巡航推力？单位是 kgf 还是 N？"

| 项 | 说明 |
|---|---|
| 字段 | `thrust.value` / `thrust.unit` / `thrust.condition` |
| 单位 | kgf → N：`× 9.80665` |
| 条件 | 静推（`V_∞=0`）还是带前进速度 |
| 陷阱 | 客户口中的"90 公斤"可能是**整机净推力**，也可能是**台架测的轴向力**——两者不是一个量（见 C-004）。**必须问清口径。** |

**追问话术**（当用户只给一个数）：
"这个数是整机净推力，还是台架上测的轴向力？两者差一个控制体口径，结果会差几十牛。"

### Q2 环境条件

> **问**："在什么环境下工作？海平面标准大气还是高原？"

| 项 | 默认（**标注为假设**） |
|---|---|
| `p_∞` | 101325 Pa（ISA 海平面） |
| `T_∞` | 288.15 K |
| `V_∞` | 0 m/s（静推） |

### Q3 桨盘直径 / 涵道外径

> **问**："桨盘直径有硬约束吗？是结构给的，还是可以自己定？"

这条**几乎总是硬约束**：它来自机架、涵道壳体、运输尺寸。
若用户说"你定"，则它变成 G2 的**设计变量**，需在 G1 给出选择依据（盘载荷 `T/A` 的工程区间）。

### Q4 转速上限

> **问**："转速有上限吗？是电机限制、减速箱限制，还是桨尖马赫数限制？"

| 约束来源 | 后果 |
|---|---|
| 电机 KV / 最大转速 | 硬约束，直接定转速 |
| 桨尖马赫数 | 软约束，通常要求 `M_tip ≤ 0.7`（民用）/ `≤ 0.85`（军用），**需向用户确认适用值** |
| 减速比 | 决定输出轴转速 |

**必算**：`M_tip = ω·R_tip / a`，其中 `a = sqrt(γRT)`。用 ISA 海平面 `a = 340.3 m/s`。

## 第 2 组：动力与结构（必问，3 项）

### Q5 电机

> **问**："用哪个电机？有 datasheet 吗？"

若用户提供了 datasheet（如 `EMRAX_188_datasheet`、`DS-215参数`），提取**两类**参数：

**① 动力参数**（决定能不能驱动）
额定功率 / 峰值功率 / 最高转速 / 效率 / 质量。

**② 几何包络**（决定轮毂能不能套上去）—— **极易漏，且漏了要到 G3 才发现**

| 必取字段 | 用途 |
|---|---|
| **电机外径** | 轮毂在电机占位段内必须 **≥ 电机外径** |
| **电机轴向长度** | 决定该段轮毂保持等直径的长度（外加两端预留） |
| 安装法兰 / 轴伸 | 影响进口段型线 |

**实例（DF90-001 / EMRAX 188）**：datasheet 首行写
「直径 | 长度 **188 mm** | **79 mm**」——**型号里的"188"就是外径（mm）**。
v8 的轮毂因此把 P4→P5 做成 Ø188 等直径段，长度 83.96 mm = 79 mm 电机 + 4.96 mm 预留。

> ⚠️ **漏掉这一项的后果**：G2 的一维方案只给"通流面积 / 半径"，
> 不会知道轮毂在某一段必须鼓到 Ø188。等到 G3 造型才发现装不上，
> 就只能**手工改几何**——而手工改几何会让几何无法由参数表复现，
> 溯源链在这里断掉。DF90-001 v8 实际就是这样发生的，见
> `cases/DF90-001/02-geometry/v8/PROVENANCE.md`。
>
> **补一个字段的成本是一句话；漏掉它的成本是一次手工重做加一条断掉的溯源。**

**关键交叉检查**（两条都要过）：

1. G2 算出的**轴功率** ≤ 电机峰值功率；
2. G2 给出的**轮毂型线**在电机占位段内处处 ≥ 电机外径。

任一不满足，方案不成立，必须回头改转速或直径。
这是 G1→G2 之间最常见的"看起来能算，实际装不上"。

### Q6 叶排数

> **问**："单转子，还是转子+静子？要不要进口导叶（IGV）？"

| 配置 | 适用 |
|---|---|
| 单转子 | 最低成本/最低重量，出口有旋流，效率低 |
| 转子 + 静子 | 最常见；静子回收旋流 |
| IGV + 转子 + 静子 | 需要预旋调节时 |

**默认（标注为假设）**：转子 + 静子。

### Q7 轴向长度 / 结构约束

## 第 3 组：材料与工艺（必问，2 项）

### Q8 材料

> **问**："叶片什么材料？注塑、复材还是金属？"

影响：许用应力（结构，不在本链范围）、**表面粗糙度（影响损失相关式）**、最小可制造厚度。

### Q9 制造工艺约束

> **问**："前尾缘半径有最小限制吗？弦长有最小值吗？"

注塑件通常要求前缘半径 ≥ 0.3–0.5 mm。这条会**直接回到 G3 的几何闸门**。
